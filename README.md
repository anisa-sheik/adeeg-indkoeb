# 🛒 Adeeg Indkøb — Web App

En moderne, mobiloptimeret React-applikation til håndtering af indkøbslister, månedligt budget og historik over tidligere køb. 

Appen er opbygget med et fanebaseret mobil-layout ("Tab-Bar") for en intuitiv og hurtig brugeroplevelse samt direkte synkronisering med Firebase Firestore i realtid.

🌐 **Prøv appen live her:** [https://adeeg-e2635.web.app/](https://adeeg-e2635.web.app/)

---

## 🚀 Funktioner

* **📊 Live Budgetstyring:** Indtast månedligt budget og følg det resterende beløb i realtid. Advarselsfarve ved overskridelse.
* **🏷️ Kategori-opdeling:** Farvekodning og opdeling af varer i kategorier (*Dagligvarer*, *Grønt & Frugt*, *Kød & Mejeri*, *Husholdning*).
* **📜 Arkivering & Historik:** Mulighed for at rydde listen og gemme købte varer i en særskilt historik-sektion med automatisk datostempel.
* **📱 Mobile-First Design:** Fanebaseret navigation (Liste, Tilføj, Historik) tilpasset smartphones.
* **⚡ Realtidssynkronisering:** Gemmer og henter data øjeblikkeligt via Firebase Firestore Cloud Database.
